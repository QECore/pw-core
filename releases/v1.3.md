# Release Notes (v1.3.0)

This release introduces the all-new **PW-Core CODEGEN**, featuring an interactive Playwright Codegen CLI that automatically captures locators, updates page registry files in real-time, and generates ready-to-run E2E test specs as you interact with your browser.

## 🌟 Release Highlights

- **[Interactive Codegen CLI (`npx pw-core codegen`)](#1-interactive-playwright-codegen-cli)**: Launch an interactive browser session to record your test actions. The CLI automatically updates your page registry with clean selectors and writes fully executable test files.
- **[Support for Multiple Tests](#2-record-multiple-tests)**: Record multiple tests (serial or parallel) within a single codegen session.
- **[Smart Registry Reuse](#3-smart-registry-reuse)**: Reuses existing registry entries instead of recreating base-level locators like standard Playwright, drastically reducing rework.
- **[Automatic Page Object Creation](#4-automatic-page-object-creation)**: Each unique URL accessed during a recording session is automatically recorded and registered as a separate page object.
- **[Auto-Generated Keys for Dynamic Locators](#5-auto-generated-keys-for-dynamic-locators)**: Elements are automatically assigned clean camelCase keys, including dynamic selectors with variables.
- **[Expanded Role Support in Registry](#6-expanded-role-support-in-registry)**: The page registry now natively supports all ARIA role options (e.g., `text`, `button`, `listbox`, `radio`, `checkbox`, `heading`, `link`, etc.) along with standard `selector` and `testId`.

> [!NOTE]
> **Hover Tracking & Recording**: While the Codegen engine highlights elements on hover to preview locator candidates in the floating control panel, recording actual **hover actions** is not supported.

## 🛠️ Key Features & Enhancements

### 1. Interactive Playwright Codegen CLI

Run a single command to start recording page elements, page actions, and assertions. It dynamically updates your registry file and builds a test spec simultaneously.

- **How to run**:
  ```bash
  npx pw-core codegen
  ```
- **Safe Mode** (prevents overriding existing selectors in your registry):
  ```bash
  npx pw-core codegen --safe
  ```

### 2. Record Multiple Tests

You can record multiple tests (both serial and parallel) within a single session, enabling you to build comprehensive test suites quickly without restarting the CLI.

### 3. Smart Registry Reuse & Page Object Mapping

- **No Redundant Locators**: If you click an element that is already registered under a different strategy (such as text, testId, or CSS selector), the generator detects and reuses the existing key rather than writing a duplicate entry.
- **URL-to-Page-Object Mapping**: As you navigate across different URLs, the codegen engine automatically generates new page configs and maps actions to their respective page objects.

### 4. Expanded Registry Role Options

You can define elements in your page config using any HTML role directly. This provides a cleaner configuration syntax and better accessibility-first automation testing:

```ts
import { createPageConfig } from 'pw-core/page'

export const config = createPageConfig({
  // New role-based registry entries:
  button: ['submit', 'cancel'],
  checkbox: ['rememberMe'],
  radio: ['agreeToTerms'],
  listbox: ['countrySelect'],
  heading: ['welcomeHeader']
})
```

## Released Tickets

### [#22 Refine Codegen Locator Generation, Checkbox Action Mapping, and Cross-Strategy Reuse](https://github.com/QECore/pw-core/issues/22)

- **Type**: Enhancement
- **Area**: `CLI / Codegen`
- **Description**: Consolidates crucial refinements to the codegen engine. Ensures high-quality locators, restricts checkbox mapping to appropriate inputs, filters out noisy style-related CSS classes, limits candidate value lengths to 50 characters, and implements cross-strategy key reuse.
- **Technical Example**:
  When clicking a checkbox element in the browser:
  - **Before**: Might generate a long class selector like `.checkbox-item-border-active` and a standard click action.
  - **After**: Automatically maps to the registry's `checkbox` array using a clean text key and records a `check()` action:
    ```ts
    // Added to registry.ts:
    checkboxes: {
      rememberMe: 'Remember Me'
    }

    // Generated in recorded test:
    await loginPage.check('rememberMe')
    ```
